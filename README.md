# simple-quiz-game
Players answer a series of general knowledge questions. The program checks answers, keeps score, calculates the percentage, and provides feedback on whether the player passed or failed. It’s a great beginner project for practicing Python basics.

Features :

Presents multiple-choice or open-ended questions.

Checks player’s answers in real-time.

Keeps track of score and calculates percentage.

Provides feedback if the player passed or failed.

Easy to extend with more questions.

Simple terminal interface.
